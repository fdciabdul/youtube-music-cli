# ymc 0.1.0 — Centennial → Minor

One hundred `0.0.x` releases built a real terminal music player. **0.1.0** leaves the micro-patch era and marks the companion product as ready for the next chapter.

## Highlights

- **Bundled web companion** — `ymc --web` / `--web-only` serves a Phosphor Console UI from every production build (no separate `build:web` step). Synced playback, queue, search, volume, shuffle/repeat/autoplay, dark/light theme.
- **Live Streams + Radio** — curated live catalog and Radio Browser / regional stations alongside the core player.
- **Win32 immersive mode** — fullscreen Bun-native player with search, library, favorites, and tray.
- **Playback reliability** — mpv IPC reconnect, stall watchdogs, mpv 0.41+ subtitle flag fix, download path via yt-dlp → youtubei → Invidious.
- **Mature TUI stack** — favorites, plugins, stats, AI chat, import/export, gapless/crossfade, equalizer, volume fade.

## Install

```bash
npm install -g @involvex/youtube-music-cli
# or
bun install -g @involvex/youtube-music-cli
```

```bash
ymc --web          # TUI + browser companion
ymc --web-only     # companion only
ymc --win32        # Windows immersive
```
