# ymc 0.2.0 — Sync & Cookie Auth

## Highlights

- **Playlist Sync** — Sync YouTube Music playlists (by ID or URL) directly into your local config with `ymc sync`. Search and list saved playlists. Uses the authenticated YouTube Music API for one-call playlist fetches.
- **Cookie-based Auth** — Use a `cookies.txt` file or extract cookies from your browser as a fallback when OAuth2 Device Flow is blocked. Supports Chrome, Edge, Brave, and Firefox. On Windows, a Python `sqlite3` fallback handles browser-locked SQLite databases.
- **Improved Shell Completions** — The `sync` command is now tab-completable (subcommands: `sync`, `sync search`, `sync list`).

## Playlist Sync

```bash
# Sync a playlist
ymc sync VLPLm90DCMQmtlk26B3JPo9E1cJULsgeUNrP
ymc sync "https://music.youtube.com/playlist?list=VLPLm90DCMQmtlk26B3JPo9E1cJULsgeUNrP"

# Search playlists
ymc sync search "lofi"

# List saved playlists
ymc sync list
```

Sync requires authentication (`ymc login` or `ymc login --cookies-file`).

## Cookie Auth

```bash
# From a cookies.txt export
ymc login --cookies-file "/path/to/cookies.txt"

# Extract from a browser
ymc login --cookies-from-browser edge
```

See [Configuration](../configuration) for details.
